git --version — проверяет текущую установленную версию программы Git на компьютере, чтобы убедиться в ее работоспособности. 
git init — инициализирует новый локальный репозиторий в текущей папке, создавая скрытый каталог .git для начала отслеживания изменений. 
git status — показывает текущее состояние рабочего каталога и индекса (какие файлы изменены, какие подготовлены к сохранению, а какие Git пока не видит). 
git add — добавляет содержимое измененных или новых файлов в индекс (staging area), подготавливая их к следующему сохранению. 
git commit — фиксирует (сохраняет) подготовленные изменения из индекса в постоянный слепок (коммит) во внутренней базе данных проекта с обязательным текстовым сообщением. 
git log — выводит журнал изменений (историю коммитов) с указанием авторов, дат и уникальных номеров (хэшей) каждого сохранения. 
git checkout — используется для переключения между различными версиями файлов, коммитами или ветками (например, git checkout master возвращает к главной ветке). 
git diff — показывает конкретную разницу между текущим состоянием файлов на диске и их последней сохраненной версией.
